pre-integration handoffs. Their production counterparts were integrated and
subsequently evolved in `First_AI_Agents/First_AI_Agents/` and
`UI_AI_Orchestrator/`.

Do not copy these snapshots over current source. They remain only as archival
inputs until the repository owner decides whether to remove the duplicated code
trees. The former per-package integration notes, manifests, addenda, and test
reports were removed during the 2026-08-17 documentation consolidation because
they described pre-integration steps and stale verification. Their exact text is
recoverable from Git history.

[Backend README](../First_AI_Agents/First_AI_Agents/README.md) and the
[desktop README](../UI_AI_Orchestrator/README.md). Older internal architecture
